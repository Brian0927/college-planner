# College Planner

清大動力機械工程學系 **114 學年入學**的四年課表與學分規劃工具。純前端、零執行期套件，沿用原網站操作與版面。

- 主修：動力機械工程學系 114 入學（129 學分）。
- 輔系：外國語文學系、計量財務金融學系、材料科學工程學系、電機工程學系，可複選。
- 規定科目附日語、德語各程度及應用課，以及粵語非學分課。語言清單不影響必修達標，學分課預設歸主修其餘選修。
- 不蒐集姓名與學號，舊檔匯入時移除個人欄位、保留課程，已移除的主修轉回 114 動力機械工程學系。
- 自動保存預設關閉，可啟用本機儲存，或匯出／匯入 JSON。

資料來源及限制詳見 [SOURCES.md](SOURCES.md)。主修依指定的 114 入學科目表；輔系採 115 學年度各系現行公告，保留原修訂日期。

計量財務金融學系七門課合計 21 學分須全修，校定加修門檻為 20。材料科學工程學系必修 9、選修至少 11。電機工程學系開課單位與抵免限制仍須系辦確認。

語文中心第 55 期均為非學分班、0 學分；停開課有註記，沒有公告的程度不自行增設。115 下班級與時段尚未收錄。115 年春季屬於 114 下，不能當作 115 下資料。

## 開發與驗證

本機啟動：python -m http.server 8080

測試：node --test tests/*.test.mjs

規則檢查：node tests/check-rulesets.mjs

頁面冒煙測試：node tests/smoke.mjs（開發環境需 jsdom）

更新快取版號：node tools/bump-build.mjs --bump

index.html 為入口；rulesets/ 放科目與學分規定，offerings/ 放班級與時段資料，engine/ 純函式計算，ui/ 負責畫面與本機狀態。新增模組後須重新產生 importmap。

可透過 GitHub Pages 發布 repo 根目錄。既有升版 workflow 僅在 main 網站檔案收到 push 時執行，以 contents:write 更新版號，不更動原有權限與觸發條件。

保留既有 114 下快照供大一下排課參考；其他學期參考班級會標示來源年度。正式開課、抵免及畢業資格以校方與系辦核定為準。
